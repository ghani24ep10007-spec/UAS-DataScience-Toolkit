# Journal & Data Science Learning Hub

Pusat belajar mandiri berbahasa Indonesia untuk literasi jurnal ilmiah, metodologi penelitian, dan Data Science.

## Isi folder
- [Website belajar](index.html)
- [Master prompt untuk semua AI](MASTER_PROMPT.md)
- [Roadmap belajar 12 minggu](ROADMAP.md)
- [Checklist review jurnal](JOURNAL_REVIEW_CHECKLIST.md)
- [Python starter](PYTHON_STARTER.py)

## Urutan belajar
1. Baca roadmap.
2. Pilih satu artikel open-access yang relevan.
3. Isi checklist review berdasarkan isi artikel.
4. Gunakan master prompt sebagai tutor, bukan sebagai pengganti pemahaman.
5. Praktikkan Python pada dataset terbuka dari UCI atau Kaggle.

## Prinsip akademik
Jangan mengarang referensi, DOI, data, atau hasil. Verifikasi artikel pada laman penerbit/repository. AI detector hanya indikator yang tidak konklusif; jangan jadikan skor sebagai bukti tunggal.
