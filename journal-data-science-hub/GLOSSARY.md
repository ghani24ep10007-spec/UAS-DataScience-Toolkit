# Glosarium Journal & Data Science

| Istilah | Arti sederhana |
|---|---|
| Abstract | Ringkasan tujuan, metode, hasil, dan kesimpulan artikel. |
| Research gap | Hal penting yang belum dijawab atau masih lemah dalam penelitian sebelumnya. |
| Novelty | Kebaruan atau kontribusi spesifik penelitian. |
| Hypothesis | Dugaan/relasi yang akan diuji secara sistematis. |
| Variable | Karakteristik yang diukur atau dianalisis. |
| Population | Seluruh kelompok sasaran penelitian. |
| Sample | Bagian populasi yang benar-benar diteliti. |
| Sampling | Cara memilih sampel. |
| Validity | Sejauh mana instrumen/analisis mengukur hal yang seharusnya diukur. |
| Reliability | Konsistensi hasil pengukuran. |
| Bias | Penyimpangan sistematis yang dapat memengaruhi hasil. |
| Dataset | Kumpulan data yang dianalisis. |
| Data cleaning | Memperbaiki format, nilai kosong, duplikasi, dan masalah data. |
| EDA | Exploratory Data Analysis; eksplorasi awal untuk memahami pola data. |
| Feature | Variabel masukan yang dipakai model. |
| Target | Variabel yang diprediksi model. |
| Regression | Model untuk memprediksi nilai numerik. |
| Classification | Model untuk memprediksi kelas/kategori. |
| Clustering | Pengelompokan data tanpa label target. |
| Overfitting | Model terlalu cocok pada data latihan dan buruk pada data baru. |
| Data leakage | Informasi dari luar data latihan bocor ke proses pelatihan/evaluasi. |
| Precision | Proporsi prediksi positif yang benar. |
| Recall | Proporsi kasus positif aktual yang berhasil ditemukan. |
| F1-score | Harmonic mean precision dan recall. |
| Reproducibility | Kemampuan mengulang analisis dengan data dan langkah yang sama. |
